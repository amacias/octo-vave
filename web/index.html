Ports & channel

The keyboard and controllers use the note channel. SysEx spacing is the pause between messages when the dashboard sends a burst of SysEx; raise it if the device drops data.

Windows MIDI ports are exclusive: release them before another app (an editor or updater) opens the device.

Sound check

Turn the FM-1's volume up and listen. Run one step at a time: each one plays a BEFORE and an AFTER, and the caption shows which is playing. Then answer whether you heard the difference described. Each step puts the synth back afterwards. Nothing is saved on the device.

Library

Each patch is saved for one firmware, in one of that firmware's formats: a stock patch holds a voice (156 DX7 params), an FX snapshot and a program number; other firmwares store parameters, CCs or SysEx as described in firmware/formats/. Sending a patch made for another firmware than the one logged on the device asks first. Files live in data/patches/, so they're easy to back up or keep in git.
