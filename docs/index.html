Install the Full Featured App

Download for Windows Windows 10 or 11, 64-bit · release notes and SHA256

  1. Double-click Octo-Vave-win64.msi. It installs for you alone: no administrator prompt, no Python. The installer isn't code-signed yet, so Windows may say Windows protected your PC: click More info, then Run anyway.
  2. Open Octo-Vave from the Start menu or the desktop. A small window keeps it running (close it to stop) and the app opens in your browser.
  3. In Chrome or Edge at http://127.0.0.1:8765, plug in the FM-1, press Connect and allow MIDI + SysEx.
  4. Browse the Firmware page and look for the orange octopus.

On macOS or Linux, or to run from source: install Python 3 (standard library only), download the ZIP or git clone the repository, and run python server.py.

What it does

Finds every free firmware

Official, the community top 10 ranked by stars and downloads, free closed-source projects, and the next 20. Paid firmware is never listed.

Tags what you're getting

Open or closed source, published checksum, one-click revert to stock, and how it installs: web, Python or M-UPGRADE.

Checks every download

Files land in a local library, verified against the SHA256 each project publishes.

Validated on a real FM-1

Installed, played, Sound-checked and reverted to stock. The exact file tested is pinned by its SHA256.

Plays the FM-1

A key bed modeled on the device, perform and FX controls, a DX7-style voice editor, a patch library and MIDI tools.

Runs on your computer

A small local server on 127.0.0.1 and a page in Chrome or Edge. No account, no cloud. Windows gets an installer; elsewhere it runs on Python.

Play it

Play and shape the FM-1 from the browser: perform controls and FX, a keyboard, favorite patches and the voice editor. Customize picks what shows.

Sound check

Check by ear that the firmware on the FM-1 answers MIDI: each step plays a short test and you mark what you heard. Results are kept per firmware.

Voice design

The FM-1 is a six-operator FM synth that speaks the DX7's SysEx. The Voice editor on FM-1 Home lays out a whole DX7 voice, so you can design sounds in the browser and hear every move on the device.

Six operators

Ratio or fixed frequency, coarse, fine and detune, a four-rate, four-level envelope drawn as you shape it, output level, velocity and mod sensitivity. Switch any operator off to hear the others.

32 algorithms

Pick an algorithm and the editor names its carriers, so you know which operators you hear and which ones shape them. Feedback included.

Pitch EG and LFO

The global pitch envelope, LFO speed, delay, wave and key sync, pitch and amp mod depth, and transpose.

Hear it live

Live send writes each change to the FM-1 as you move it, as a DX7 parameter change (F0 43 10 pp qq vv F7). Send whole voice pushes all 156 parameters at once.

Thousands of DX7 sounds

Import any DX7 .syx: a single voice or a 32-voice bank, then pick a voice from the bank. Export yours the same way.

Keep what you make

Init, Randomize, then Save to Library with notes and tags. Notes come back with the patch; star it to pin it on FM-1 Home.

DX7-compatible SysEx. The FM-1 doesn't send its current voice back, so the editor starts from INIT or an imported voice. Live send writes each change as you move it. Edits change the active voice; save on the device to keep them there. The voice editor targets the stock firmware; community firmware has its own sound engines.
